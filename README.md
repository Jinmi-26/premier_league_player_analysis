# Premier League Player Analysis

This is my first Python project, created while learning the fundamentals of Python.

The project analyses a football player's performance in a Premier League match using basic match statistics.

## Features

The program stores player and match information and calculates:

- Goal contributions
- Passing accuracy
- Shooting accuracy
- Conversion rate
- Overall performance based on selected performance thresholds

## Python Concepts Used

- Variables
- Strings
- Arithmetic operators
- Comparison operators
- If statements
- F-strings
- String methods
- Basic calculations

## What I Learned

This project helped me practise combining individual Python concepts into one working program rather than learning each concept in isolation.

It also gave me experience using Git and GitHub to track and publish a project for the first time.
